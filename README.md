# Smart House IoT

A personal Internet of Things (IoT) project demonstrating remote control of smart-home functions using an ESP32 microcontroller and the Blynk platform.

## Project Overview

This project involved developing a small smart-house prototype. Three LEDs represented lights in three different rooms, while a servo motor represented a remotely controlled door mechanism.

The Blynk mobile application provided a remote interface for controlling the three room lights and the servo motor independently.

An I²C LCD display provided system feedback by displaying startup messages and the current ON/OFF status of the LEDs.

The documentation has been reconstructed retrospectively from the original project and the information currently available.

## Features

- Independent remote control of three room lights using Blynk.
- Remote operation of a servo motor to demonstrate door control.
- LCD startup messages, including "Smart House Loading" and "Smart House Ready".
- LCD display of the current LED ON/OFF statuses.
- ESP32-based IoT prototype.

## Hardware and Technologies

- ESP32 microcontroller
- Three LEDs
- Servo motor
- I²C LCD display
- Blynk IoT platform
- Arduino programming environment
