# Smart House IoT

A personal Internet of Things (IoT) project demonstrating remote control of basic smart-home functions using an ESP32 microcontroller and the Blynk platform.

## Project Overview

This project involved building a small smart-house prototype. LEDs represented household lights, while a servo motor represented a door mechanism. The Blynk mobile application provided a remote interface for controlling these components.

The documentation has been reconstructed retrospectively from the original project and the information currently available.

## Features

* Remote control of household lights represented by LEDs.
* Remote operation of a servo motor to demonstrate door control.
* ESP32-based IoT prototype using Blynk.

## Hardware and Technologies

* ESP32 microcontroller
* LEDs
* Servo motor
* Blynk IoT platform
* Arduino programming environment
