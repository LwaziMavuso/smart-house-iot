# Smart House IoT

A personal IoT project using an ESP32, Blynk, LEDs, and a servo motor to demonstrate remote control of basic smart-home functions.

## Project Overview

This project is a small smart-house prototype designed to demonstrate how IoT can be used to remotely control devices within a home.

The LEDs represent household lights, while the servo motor represents a smart door. Blynk is used as the remote control interface, allowing the connected devices to be operated through a mobile device.

## Technologies Used

- ESP32
- Blynk
- Arduino IDE
- LEDs
- Servo Motor
