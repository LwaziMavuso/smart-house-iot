# Smart House IoT — Technical Project Report

## 1. Project Overview

The Smart House IoT project is a personal project developed to explore how Internet of Things (IoT) technology can be used to control household functions remotely.

The prototype used an ESP32 microcontroller, LEDs to represent household lights, and a servo motor to demonstrate remote door control. The Blynk platform provided the interface for controlling the connected components.

This report has been reconstructed retrospectively because the original project documentation was not retained.

## 2. Project Objectives

The main objectives of the project were:

- To explore IoT-based remote control.
- To use an ESP32 microcontroller in a smart-home application.
- To demonstrate household lighting control using LEDs.
- To demonstrate door control using a servo motor.
- To gain practical experience connecting hardware with a mobile application.

## 4. System Operation

The ESP32 served as the central microcontroller for the prototype.

The Blynk mobile application provided a remote interface for controlling the connected components.

The LEDs represented household lights and could be controlled remotely. The servo motor demonstrated a door mechanism that could be operated remotely through Blynk.
